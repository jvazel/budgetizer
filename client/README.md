# Budgetizer Frontend (React + TypeScript + Vite)

Cette partie contient l'application Single Page Application (SPA) et PWA de **Budgetizer**.

## 🛠️ Stack Technique
- **Framework** : React 19 + TypeScript
- **Bundler** : Vite 6
- **Styling** : Tailwind CSS
- **PWA** : Vite PWA Plugin (`@vite-pwa/plugin`)
- **Tests** : Vitest + React Testing Library (`@testing-library/react`)

## 🚀 Commandes utiles

```bash
# Lancement du serveur de dev
npm run dev

# Vérification du typage TypeScript
npx tsc --noEmit

# Compilation de production
npm run build

# Exécution des tests unitaires
npm test
```
